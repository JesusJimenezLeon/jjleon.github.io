Las siguientes son las instrucciones que seguí para montar esta página usando GitHub Pages:

1. Descargar e instalar Git Bash.
2. Descargar e instalar Ruby para Windows.
3. Iniciar sesión en Git Hub. Buscar un template (yo utilicé el de Academic Pages [link](https://academicpages.github.io/markdown/) "Academic Pages") y hacer FORK. 
4. Crear una carpeta en local y clonar el repositorio.
5. Crear el SSH key.
    1. Crear archivo config
    2. Agregar SSH-key a cuenta de GitHub 
    3. Cambiar repositorios para usar el host correcto y probar conexión. 
6. Correr el agente, cargar claves y probar conexión.


Para hacer el host:

1. Instalar Visual Studio Code (para modificar los archivos posteriormente).
2. Ir a GitHub y hacer "deploy from a branch" (esperar unos minutos a que se haga el deploy).

Flujo para hacer cambios:

1. Abrir Git Bash e ir al folder del proyecto 
2. Ver en local.
3. Hacer cambios en VS Code.
5. Añadir cambios (add, commit, push)
